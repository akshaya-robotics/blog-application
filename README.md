# Blog Application

A simple web-based blogging platform that allows users to create, publish, manage, search, and view blog posts.

## Features

- User Registration
- User Login
- Dashboard
- Create and Publish Blogs
- Author Information
- Blog Categories
- Search Blogs
- Category Filtering
- Edit Blogs
- Delete Blogs
- Read More / Blog Details
- Home Page with Recent Blog Posts

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
